# vkt1414.github.io

Privacy-conscious professional portfolio for Vamsi Thiriveedhi, focused on molecular diagnostics, clinical data engineering, and reproducible medical-imaging AI.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm ci
npm run build
```

The static site is written to `out/`. A GitHub Actions workflow deploys that folder to GitHub Pages whenever `main` changes.
